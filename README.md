## Названия справочников
1.Категории игровых ассетов
2.Игровые ассеты

1. Справочник «Категории игровых ассетов»

Примеры категорий: персонажи, оружие, props, транспорт, растения

Поля справочника:
category_id (целое число)

category_name (текст)

description (текст)
Описание категории и ее особенностей.

uniqueness_type (текст)
Тип использования ассетов данной категории.
Примеры значений: уникальный, переиспользуемый

Уникальные ассеты обычно создаются под конкретную задачу, например главный персонаж;
переиспользуемые могут многократно использоваться в разных сценах, например растения, мебель, props.

detail_level (целое число)
Уровень детализации ассетов данной категории.
1. низкий
2. средний
3. высокий

average_file_size (число с фиксированной запятой)
Средний размер файлов ассетов данной категории в мегабайтах


2. Справочник «Игровые ассеты»

Справочник содержит информацию о конкретных игровых ассетах.

Поля справочника:
asset_id (целое число)

asset_name (текст)

source_project (текст)
Название игры или проекта, в котором используется ассет.

creation_date (дата)
Дата создания ассета.

polygon_count (целое число)
Количество полигонов в модели.

material_count (целое число)
Количество материалов, используемых в ассете.

production_hours (целое число)
Количество часов, затраченных на создание ассета.

asset_price (число с фиксированной запятой)
Стоимость ассета

category_id (целое число)
Поле использует значения из справочника «Категории игровых ассетов».

Связь справочников

Справочник «Игровые ассеты» зависит от справочника «Категории игровых ассетов», так как поле category_id в справочнике ассетов использует значения из справочника категорий.

каждый ассет относится к одной категории, одна категория может содержать много ассетов, при вводе ассета категория должна выбираться из существующего списка категорий.
